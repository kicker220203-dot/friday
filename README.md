# Пятница v0.5.1-stable

Стабильная веб-сборка перед AI.

## Что изменилось
- голосовая сессия стала безопаснее: если продолжения нет, она тихо заканчивается;
- именованные таймеры и несколько таймеров одновременно;
- структурированная память: профиль / проекты / решения / заметки;
- настройки голосовой сессии, окна ожидания и диагностики;
- подтверждение очистки памяти и таймеров;
- меньше технических подсказок по умолчанию;
- сохранена миграция данных из v0.5-web;
- старый service worker/cache удаляется.

## Голосовые примеры
- `Поставь таймер пицца на 10 минут`
- `Сколько осталось пицца`
- `Отмени таймер пицца`
- `Запомни в проект Пятница, что AI подключаем через backend`
- `Что ты помнишь о Пятнице?`
- `Забудь AI подключаем через backend`

AI намеренно ещё не подключён: API-ключ нельзя хранить прямо в клиентском JavaScript. Следующий крупный этап — backend-прокси и v0.6-web-ai.
